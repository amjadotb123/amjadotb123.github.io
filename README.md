# منصة معرض الأعمال

موقع شخصي احترافي لعرض الأعمال أمام المدراء وجهات التوظيف — عربي (RTL)، متجاوب مع الجوال، بوضع داكن وفاتح، ودراسة حالة تفاعلية لكل مشروع.

## التعديل
كل المحتوى في ملف واحد: **`data.js`**
- `profile`: اسمك، مسمّاك، البريد، رابط السيرة الذاتية PDF، روابط التواصل.
- `projects`: المشاريع. اجعل `featured: true` لأقوى مشروع ليظهر بشكل كبير. ضع الصور في `assets/`.
- `stats`, `skills`, `experience`, `principles`.

> نصيحة: اكتب في كل مشروع **التحدّي ← الحل ← النتيجة بالأرقام**؛ هذا أكثر ما يلفت نظر المدراء.

## التشغيل محليًا
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
